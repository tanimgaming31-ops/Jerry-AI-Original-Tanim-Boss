# Changelog

## 0.3.0-live-voice — development, 6 November 2026

- Original Gemini Developer API v1beta Live WebSocket and explicit model discovery.
- Foreground PCM capture/resampling/playback, audio focus, bounded queues, manual
  activity/barge-in signaling, immediate playback invalidation and stale-event guards.
- Session states, setup timeout, three bounded reconnect attempts, in-memory
  resumption, mute/stop, focus-loss/background shutdown and transient captions.
- Keystore-backed encrypted user key, persistent voice/model/language/persona
  preferences and exact English/Bengali voice settings/Stop/Mute controls.
- Owner's 54-group inventory, six honest status categories, complete structured
  backlog, privacy/checklist docs and expanded JVM/wire/instrumentation tests.
- App label Jerry AI Original; application ID unchanged. Existing action/UI/theme
  behavior retained. No user memories/database were migrated or deleted.
- Provider and physical-device acceptance remain pending; no complete Phase 1 or
  background/wake-word support is claimed. No production release.
